FrameGen Manager — 使用说明
================================

这是什么
--------
给 RTX 20 / 30 系显卡的游戏开启 DLSS 帧生成的小工具。
基于开源项目 sdli1995/dlssg_for_sm86，本工具负责把需要的文件放到对的位置、
并在库里自动找到你的游戏。

怎么用（三步）
--------------
  1. 双击 framegen-manager.exe

  2. 让程序知道你游戏的目录，两种方式任选：
     · 点「扫描 Steam / Epic / WeGame」，找到你的游戏，点「用作部署目录」
     · 或者直接点「选择目录...」，手动选到游戏「渲染 EXE」所在的文件夹
       （通常在 ...\Binaries\Win64\ 这种位置，不是游戏根目录）

  3. 先在「上游资产」卡片点「下载 / 更新资产」把文件下下来，
     再在「部署」卡片点「部署」

  部署完进游戏，在画面设置里打开 DLSS 帧生成，选 2X / 3X / 4X。


会往游戏目录放什么
------------------
  version.dll         代理入口（如果这个名字被占用，会自动换 winmm / dinput8 /
                      winhttp / dxgi 里的一个）
  dlssg_sm86.ini      配置（RTX 20 系会自动把 Router 改成 SM75）
  nvngx_dlssg.dll     DLSS 帧生成运行库
  nvngx_dlss.dll      DLSS 超分运行库

  一共约 79 MB。部署前会先备份被覆盖的原文件，随时可以在「部署」卡片点
  「还原」把游戏目录恢复原样。


什么时候不要用
--------------
  · 游戏有内核级反作弊（EAC / BattlEye / Vanguard 等）
    —— 程序检测到会直接拦住你，因为改游戏文件有封号风险
  · 显卡是 RTX 40 / 50 系 —— 原生就支持帧生成，不需要本工具
  · 不是 NVIDIA 显卡


显卡驱动要注意
--------------
  帧生成需要比较新的显卡驱动。程序启动时会自己检测，低于 591.86 会在界面上标红，
  点「部署」时还会再问你一次。
  看到这个红字就先去 NVIDIA 官网更新显卡驱动再来装，否则装了多半也不生效。


显卡名称伪装（高级 · 可选 · 谨慎）
----------------------------------
  这个功能不是必须的，默认是收起的。
  只有在某个游戏里「帧生成」选项根本不出现、而且你已经按上面三步正常部署过时，
  才建议试它。作用是把注册表里的显卡名字改成 50 系，骗过只认型号的游戏。

  · 型号只能从下拉名单里选（5090 / 5080 / 5070 Ti / 5070 / 5060 Ti / 5060），
    不让手动输入，就是怕你把型号填错
  · 改之前程序会先备份原值并读回校验，校验通过才动注册表
  · 会弹一次管理员确认框（UAC），而且【重启之后才生效】
  · 随时能还原，两种目标任选：
      还原为驱动记录的名称 = 彻底去掉伪装，回到你的真实型号
      还原为改动前的值     = 回到本程序第一次动手之前的状态

  ! 副作用，动手前请务必看完：
    · 显卡名和硬件 ID 对不上，内核级反作弊可能判定异常，有封号风险
    · NVIDIA App / 驱动安装程序可能认错型号，导致驱动更新失败
    · 重装驱动或大版本更新后会被重置
    · dxdiag、设备管理器、任务管理器里显示的名称都会变
    · 不保证一定生效：如果游戏是看硬件 ID 判断的，改名没有用
    · 部分按型号生效的 NVIDIA 功能（DLSS 覆盖、控制面板选项）可能受影响


常见问题
--------
Q: Windows 弹「已保护你的电脑」怎么办？
A: 程序没有买数字签名证书，这是所有未签名软件的通病。
   点「更多信息」→「仍要运行」即可。

Q: 下载资产失败，提示官方源连不上？
A: 国内访问 GitHub 经常间歇性不通。界面上会出现「改用备用源重试」按钮，
   点一下就行，不用自己填网址。

Q: 下载还是很慢怎么办？
A: 在「上游资产」卡片点「测速」，等十几秒，它会把你这条线路上每个源的速度都测出来，
   点一下最快那个就选中了。不选也行 —— 程序每次下载成功都会记住各源的实际速度，
   下次按速度从快到慢试；下载中要是发现某个源太慢（低于 300 KB/s），会自动换下一个。

Q: 部署了但游戏里没有帧生成选项？
A: 第一步，先确认显卡驱动不低于 591.86（界面上会标红提醒，看到红字就先去更新驱动）。
   第二步，在游戏里把 DLSS 打开。
   第三步，在「上游资产」卡片点「重新检测入口」，换一个代理入口再部署一次。
   如果都试过还是不行，再看上面「显卡名称伪装」那一节 —— 但那个有封号风险，请自己判断。

Q: 部署好了，游戏里还是没有帧生成？
A: 先看「上游资产」卡片里这一行：「硬件加速 GPU 计划」。DLSS 帧生成要求它是开启的。
   如果显示「已关闭」，点旁边的「去设置」，在打开的设置页里把它打开（改完要重启一次
   电脑）。显示「未知」的话多半本来就是开的（Win11 默认开启），点「去设置」可以看到
   真实状态。程序只显示状态、不会替你改系统设置。

Q: 我的游戏是 WeGame 上的，扫描扫不出来？
A: 正常。WeGame 把游戏安装位置记在注册表里，但那个格式没有官方文档，程序只能按社区
   资料保守地猜，扫不出来比列一堆错的好。直接点「选择目录」，选到游戏渲染 EXE 所在的
   那个文件夹（通常是 ...\\Binaries\\Win64 之类），后面的步骤和别的平台一样。

Q: 怎么知道有没有出新版本？
A: 程序启动时会自己查一次。查到就在标题栏出现「有新版本 x.y.z」按钮，点一下
   就去下载页；想手动再查一次，点标题栏的「检查更新」。

Q: 怎么彻底卸载？
A: 先在游戏卡片里点「还原」清理游戏目录，再删掉本程序文件夹即可
   —— 备份和设置都在里面。
   如果你用过更早的版本，可能还留着 %APPDATA%\FrameGen-Manager，一并删掉即可。


数据放在哪
----------
  全部放在程序所在的那个文件夹里：

    assets\                 下载的资产（约 79 MB）
    backups\                游戏部署备份、显卡名备份
    framegen-manager.json    设置

  想做成绿色便携版：整个文件夹拷走就行，东西全在里面。
  程序目录不可写时（比如装在 C:\Program Files），备份和设置会自动回退到
  %APPDATA%\FrameGen-Manager\。

  ! 注意：备份跟着程序目录走，删掉程序文件夹备份就一起没了，
    之后就没法一键还原游戏目录。要还原请趁早。


第三方说明
----------
本工具不分发、也不打包 NVIDIA 的任何文件。
nvngx_dlssg.dll / nvngx_dlss.dll 由用户在本程序内主动触发下载，取自社区仓库
RankFTW/rhi-repo 的 GitHub Releases，文件本身是 NVIDIA 官方签名（程序解压后会
校验签名者必须是 NVIDIA，不符就丢弃）。这两个文件的版权归 NVIDIA。

本工具与 NVIDIA、sdli1995、RankFTW 均无关联。
