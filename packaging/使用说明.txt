FrameGen Manager — 使用说明
================================

这是什么
--------
给 RTX 20 / 30 系显卡的游戏开启 DLSS 帧生成的小工具。
基于开源项目 sdli1995/dlssg_for_sm86，本工具负责把需要的文件放到对的位置、
并在库里自动找到你的游戏。

怎么用（三步）
--------------
  1. 双击 framegen-manager.exe

  2. 让程序知道你游戏的目录，两种方式任选：
     · 点「扫描 Steam / Epic / WeGame」，找到你的游戏，点「用作部署目录」
     · 或者直接点「选择目录...」，手动选到游戏「渲染 EXE」所在的文件夹
       （通常在 ...\Binaries\Win64\ 这种位置，不是游戏根目录）

  3. 先在「上游资产」卡片点「下载 / 更新资产」把文件下下来，
     再在「部署」卡片点「部署」

  部署完进游戏，在画面设置里打开 DLSS 帧生成，选 2X / 3X / 4X（出厂默认上限就是 4X，
想要 6X 或更快的档位见下面的问答）。


会往游戏目录放什么
------------------
  version.dll         代理入口（如果这个名字被占用，会自动换 winmm / dbghelp /
                      dinput8 / dxgi / d3d12 里的一个）
  dlssg_sm86.ini      配置（出厂只有两个开关）
  nvngx_dlssg.dll     DLSS 帧生成运行库（只在你游戏目录里没有时才放）
  nvngx_dlss.dll      DLSS 超分运行库（只在你游戏目录里没有时才放）

  为什么要「只缺才放」：很多游戏目录本来就带着它自己的这两个运行库，而且和游戏
  自己的 DLSS 版本是配套的；覆盖它们反而可能让帧生成不生效。所以程序会先看一遍：
  已有的一个都不动（界面上会写明「游戏目录已有 xxx，用游戏自带的那份」），
  缺哪个才补哪个。

  两个运行库仍然会下载到资产目录备用（网速慢的时候可以用「导入压缩包」塞进去）。
  部署前会先备份被覆盖的原文件，随时可以在「部署」卡片点「还原」把游戏目录恢复原样。


什么时候不要用
--------------
  · 游戏有内核级反作弊（EAC / BattlEye / Vanguard 等）
    —— 程序检测到会直接拦住你，因为改游戏文件有封号风险
  · 显卡是 RTX 40 / 50 系 —— 原生就支持帧生成，不需要本工具
  · 不是 NVIDIA 显卡


显卡驱动要注意
--------------
  帧生成需要比较新的显卡驱动。程序启动时会自己检测，低于 580.0（R580）会在界面上标红，
  点「部署」时还会再问你一次。
  更旧的驱动会自动回退到 PTX 内核。


显卡名称伪装（高级 · 可选 · 谨慎）
----------------------------------
  这个功能不是必须的，默认是收起的。
  只有在某个游戏里「帧生成」选项根本不出现、而且你已经按上面三步正常部署过时，
  才建议试它。作用是把注册表里的显卡名字改成 50 系，骗过只认型号的游戏。

  · 型号只能从下拉名单里选（5090 / 5080 / 5070 Ti / 5070 / 5060 Ti / 5060），
    不让手动输入，就是怕你把型号填错
  · 改之前程序会先备份原值并读回校验，校验通过才动注册表
  · 会弹一次管理员确认框（UAC），而且【重启之后才生效】
  · 随时能还原，两种目标任选：
      还原为驱动记录的名称 = 彻底去掉伪装，回到你的真实型号
      还原为改动前的值     = 回到本程序第一次动手之前的状态

  ! 副作用，动手前请务必看完：
    · 显卡名和硬件 ID 对不上，内核级反作弊可能判定异常，有封号风险
    · NVIDIA App / 驱动安装程序可能认错型号，导致驱动更新失败
    · 重装驱动或大版本更新后会被重置
    · dxdiag、设备管理器、任务管理器里显示的名称都会变
    · 不保证一定生效：如果游戏是看硬件 ID 判断的，改名没有用
    · 部分按型号生效的 NVIDIA 功能（DLSS 覆盖、控制面板选项）可能受影响


常见问题
--------
Q: Windows 弹「已保护你的电脑」怎么办？
A: 程序没有买数字签名证书，这是所有未签名软件的通病。
   点「更多信息」→「仍要运行」即可。

Q: 下载资产失败，提示官方源连不上？
A: 国内访问 GitHub 经常间歇性不通。界面上会出现「改用备用源重试」按钮，
   点一下就行，不用自己填网址。

Q: 下载还是很慢怎么办？
A: 在「上游资产」卡片点「测速」，等十几秒，它会把你这条线路上每个源的速度都测出来，
   点一下最快那个就选中了。不选也行 —— 程序每次下载成功都会记住各源的实际速度，
   下次按速度从快到慢试。下载中不会再因为「慢」换源了 —— 多慢都会让它下完，
   只有某个源卡住不动（连续 5 分钟一个字节都收不到）才会自动换下一个。

Q: 为什么每次打开都要重新扫描一遍？
A: 现在不用了。扫描一次的结果会记住，下次打开直接显示（列表右上角写着上次扫描的时间）。
   程序不会自己偷偷扫盘，想刷新就点「扫描 Steam / Epic / WeGame」。
   游戏卸载了、安装目录已经不存在的条目会自动跳过。

Q: 所有下载源都很慢（几十 KB/s），有没有别的办法？
A: 有，绕开下载：去发布页/网盘拿到几个 zip（作者的上游包 + 两个 DLSS 运行库包），
   打开程序 →「上游资产」→ 点「导入压缩包…」，在弹窗里把它们一起选中（可以多选），
   剩下的程序自己做（解压、找文件、校验、放到位）。
   校验只看文件本身：代理 DLL 必须是作者的签名证书，两个运行库必须是 NVIDIA 签名；
   配置文件没有签名，程序会检查它的结构像不像一份正常配置。
   对不上会弹窗告诉你原因 —— 你可以只装没问题的，也可以坚持全部导入（会写进日志）。

Q: 手上有别人发来的文件，能直接装吗？
A: 能，做法同上。程序只认内容：签名对得上就装（上游更新了版本也照收），
   对不上会弹窗提醒，由你自己决定。

Q: 我有个游戏扫不出来怎么办？
A: 先确认它是装在 Steam / Epic / WeGame 里的吗（程序只扫这三个平台的清单）。
   如果是用游戏自己的启动器装的（鸣潮官方启动器、网易游戏中心、各种第三方启动器），
   任何按平台清单扫描的工具都看不到它 —— 请用「选择目录...」指到游戏渲染 EXE 所在的
   文件夹，再点「存到游戏库」。
   如果它确实在 Steam 里却被漏了：把 exe 旁边 logs 目录里的 framegen.log（本次运行）
   或 framegen.prev.log（上一次运行）发给作者 —— 日志会写清「读了几个清单、
   哪个被跳过、为什么」。logs 目录里永远只有这两个文件，不会越攒越多。

Q: 我的游戏不在 Steam / Epic / WeGame 里，能加进列表吗？
A: 能。用「选择目录...」指到游戏渲染 EXE 所在的文件夹（或者把路径粘到输入框点「应用」），
   再点「存到游戏库」，它就会带着「手动」标记进列表，以后直接在这儿选它、部署、还原。
   不想要了点那行的「移除」；重新扫描也不会把它冲掉。

Q: 我是 RTX 20 系，还能用吗？
A: 能，而且**什么都不用额外设置**。同一套文件（根目录的 version.dll + 出厂 dlssg_sm86.ini）
   在 20 系和 30 系上都能用，不需要改任何键。点「下载 / 更新资产」再「部署」就行。

Q: 我是 GTX 16 系（1630 / 1650 / 1660），能用吗？
A: 不能。GTX 16 系和 RTX 20 系虽然同是 Turing，但它没有 Tensor Core，DLSS 帧生成在
   硬件上就跑不了，换哪个版本都一样。所以程序会直接禁止部署，免得白折腾一场。

Q: 部署了但游戏里没有帧生成选项？
A: 第一步，先确认显卡驱动在 R580 以上（低于它界面会标红提醒；更旧的驱动会自动回退到
   PTX 内核）。
   第二步，在游戏里把 DLSS 打开。
   第三步，在「上游资产」卡片点「重新检测入口」，换一个代理入口再部署一次。
   第四步：把部署进去的 dlssg_sm86.ini 里 [Logging] Level 改成 2，
   再进一次游戏，然后点「部署」卡片上的「打开日志」按钮 —— 日志会写明帧生成被哪一关
   挡住的（硬件加速 GPU 计划 / 驱动版本 / 显卡能力查询 / CreateFeature 的返回值）。
   如果还是不行：先把资产更新到最新（点「下载 / 更新资产」）再部署一次；仍然不行才考虑上面
   「显卡名称伪装」那一节（有封号风险，请自己判断）。

Q: 想要 6X（而不是出厂默认的 4X）怎么办？
A: 在「部署」卡片上把「倍率上限」选成 6X，再点「部署」就行 —— 工具会把 6X 写进**部署到游戏
   目录的那份** ini（资产目录里的原文件不动）。注意两点：游戏自带动态倍率时会跑到这里写的
   上限，6X 对不少人偏高（上游 issue #497 / #499）；游戏自己的插件只支持 4X 时，选 6X 也只有
   4X。上游自己也说这个做法比较脆弱，下一版要重新评估。

Q: 「优化等级」选哪个好？
A: 默认的 1 就是「全部加速、画面与官方逐位一致」，一般不用动。
   0 = 用原厂内核、完全不加速（最保守）；2 / 3 更快，但图像内核有损、画面不再与官方逐位一致
   （2 对官方画面的 PSNR 约 50 dB 以上），而且只在最新版上有效。选了 2 / 3 画质变化要自己判断。

Q: 玩着玩着画面出现闪烁？
A: 先把资产更新到最新（点「下载 / 更新资产」）并重新「部署」一次；仍然闪烁就把「优化等级」
   选回 1、倍率降到 4X 再试，并确认显卡驱动是新的。

Q: 某个游戏明明装了却没有帧生成选项（比如鸣潮）？
A: 这类游戏自己按显卡型号 / 架构决定给不给你开。按这个顺序试：
   ①先把资产更新到最新（点「下载 / 更新资产」）再「部署」一次 —— 代理自己会处理架构判断，
     很多这类游戏这样就放开了。
   ②仍然不出现选项时，试上游的 INI 键 [Compatibility] SpoofArchToGame：写进**部署到游戏目录的
     那份** dlssg_sm86.ini，只影响这一个游戏，不动注册表、不需要管理员权限。
   ③本工具的「显卡名称伪装」是最后手段（改注册表、要管理员、影响整机），有封号风险。
   上游还有一份进阶键文档（Router / SM75Family / KernelImage / SpoofArchToGame / 抓取与诊断），
   在它仓库里的 docs/INSTALL.md。

Q: 部署好了，游戏里还是没有帧生成？
A: 先看「上游资产」卡片里这一行：「硬件加速 GPU 计划」。DLSS 帧生成要求它是开启的。
   如果显示「已关闭」，点旁边的「去设置」，在打开的设置页里把它打开（改完要重启一次
   电脑）。显示「未知」的话多半本来就是开的（Win11 默认开启），点「去设置」可以看到
   真实状态。程序只显示状态、不会替你改系统设置。

Q: 我的游戏是 WeGame 上的，扫描扫不出来？
A: 正常。WeGame 把游戏安装位置记在注册表里，但那个格式没有官方文档，程序只能按社区
   资料保守地猜，扫不出来比列一堆错的好。直接点「选择目录」，选到游戏渲染 EXE 所在的
   那个文件夹（通常是 ...\\Binaries\\Win64 之类），后面的步骤和别的平台一样。

Q: 怎么彻底卸载？
A: 先在游戏卡片里点「还原」清理游戏目录，再删掉本程序文件夹即可
   —— 备份和设置都在里面。
   如果你用过更早的版本，可能还留着 %APPDATA%\FrameGen-Manager，一并删掉即可。


数据放在哪
----------
  全部放在程序所在的那个文件夹里：

    assets\                 下载的资产（约 95 MB）
    backups\                游戏部署备份、显卡名备份
    framegen-manager.json    设置

  想做成绿色便携版：整个文件夹拷走就行，东西全在里面。
  程序目录不可写时（比如装在 C:\Program Files），备份和设置会自动回退到
  %APPDATA%\FrameGen-Manager\。

  ! 注意：备份跟着程序目录走，删掉程序文件夹备份就一起没了，
    之后就没法一键还原游戏目录。要还原请趁早。


第三方说明
----------
本工具不分发、也不打包 NVIDIA 的任何文件。
nvngx_dlssg.dll / nvngx_dlss.dll 由用户在本程序内主动触发下载，取自社区仓库
RankFTW/rhi-repo 的 GitHub Releases，文件本身是 NVIDIA 官方签名（程序解压后会
校验签名者必须是 NVIDIA，不符就丢弃）。这两个文件的版权归 NVIDIA。

本工具与 NVIDIA、sdli1995、RankFTW 均无关联。
